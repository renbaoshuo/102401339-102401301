# 校园失物招领小程序 · 页面流程设计说明

Figma 中原有的单页与旧状态画板已在 Figma 中隐藏并保留，便于检查主页面和单独切图。新增四组流程画板把主页面放在各自流程的开头，后接中间过渡态、成功态和异常分支。组内每台手机及文字、按钮、图标均有命名图层；物品照片和美术装饰沿用已生成的位图素材。

## 01 首页与搜索（8 帧）

首页 → 首页加载 → 首页失败；搜索输入联想 → 搜索结果 → 搜索加载 → 无匹配结果 → 筛选展开。加载和失败是首页或搜索结果的分支，不表示用户必须依次经过每一帧。

## 02 发布信息（7 帧）

发布信息 → 表单校验 → 选择图片 → 图片上传 → 提交中 → 发布成功／发布失败。校验和失败为异常反馈，失败后草稿保留。

## 03 详情与认领（6 帧）

信息详情 → 大图查看／认领确认 → 联系中 → 联系成功 → 复制提示。大图查看为详情页独立分支。

## 04 我的发布与编辑（8 帧）

我的发布 → 标记已找回确认 → 状态更新中；编辑信息 → 编辑校验 → 保存中 → 编辑成功／保存失败。

四组流程画板均可在 `integrated/` 找到 SVG 与 PNG；`states/` 保留 22 个独立状态的 SVG 与 PNG。原始页面和已生成素材继续位于导出包根目录及 `assets/`。三栏底栏的「发布」按钮居中并使用强调色，消息入口已移除；顶部不含系统时间、电量等状态栏元素。
